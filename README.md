# ルーティン タイムライン

服薬・筋トレ・勉強など、種類の違うルーティンを1本のタイムラインに統合して可視化する個人用アプリです。

## 特徴

- ルーティン登録（名前・カテゴリ・アイコン・目標頻度）
- 目標頻度: 毎日 / 週1〜6回。ルーティン管理から後で変更できます（週は月曜始まり、同じ日に複数回記録しても1回と数えます）
  - 毎日の目標は「連続日数」、週の目標は「連続達成週数」で連続記録を数えます
  - 今日の達成状況は、今週の目標をすでに達成した週目標ルーティンを除いて数えます（休んでOK）
- カレンダー表示: 月単位で記録をカテゴリ色のドットで表示。ルーティンで絞り込むと、週ごとの記録回数 / 目標も確認できます。日付をタップするとその日の記録を表示
- ワンタップで記録、または日時・メモ付きで詳細記録
- カテゴリの異なるルーティンを色分けしつつ時系列で1本にまとめたタイムライン表示
- 今日の達成状況サマリー
- 統計表示: 全体の連続記録日数・直近7日の記録数・累計、ルーティンごとの連続日数／最長連続／達成率／直近14日の記録ストリップ
- 各ルーティンのカードに現在の連続日数（🔥）を表示（今日まだ記録していなくても、昨日まで続いていれば連続は途切れません）
- 削除・元に戻す（Undo）
- ライト/ダークモード対応

## 使い方

`index.html` をブラウザで直接開くだけで動作します。ビルドや依存関係のインストールは不要です。

## データ保存

すべてのデータはブラウザの localStorage に保存されます。バックエンドはなく、端末・ブラウザごとにデータは独立しています。

## 技術構成

Vanilla HTML / CSS / JavaScript のみ（フレームワーク・外部ライブラリ不使用）。
