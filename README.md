# ルーティン タイムライン

服薬・筋トレ・勉強など、種類の違うルーティンを1本のタイムラインに統合して可視化する個人用アプリです。

## 特徴

- ルーティン登録（名前・カテゴリ・アイコン）
- ワンタップで記録、または日時・メモ付きで詳細記録
- カテゴリの異なるルーティンを色分けしつつ時系列で1本にまとめたタイムライン表示
- 今日の達成状況サマリー
- 削除・元に戻す（Undo）
- ライト/ダークモード対応

## 使い方

`index.html` をブラウザで直接開くだけで動作します。ビルドや依存関係のインストールは不要です。

## データ保存

すべてのデータはブラウザの localStorage に保存されます。バックエンドはなく、端末・ブラウザごとにデータは独立しています。

## 技術構成

Vanilla HTML / CSS / JavaScript のみ（フレームワーク・外部ライブラリ不使用）。
